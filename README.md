# Lrebel

Пошаговая стратегия в стиле Rebel Star (DOS). Написана на Си, архитектура
двухуровневая: верхний уровень (логика) работает через абстрактные функции
платформенного уровня, нижний уровень реализует их для конкретной ОС.

## Сборка (этапы 1–2)

Зависимости: SDL2 (dev-пакет). Заголовки и библиотека находятся через
pkg-config, при его отсутствии — через sdl2-config.

```
make          # соберёт build/lrebel
make run      # запуск (из корня репозитория)
make clean    # очистка
```

Структура:

- `src/portable_posix.h/.c` — нижний (платформенный) уровень: SDL2, Linux/macOS;
  окно, отрисовка кадра, загрузка изображений (PNG через встроенный stb_image.h,
  в том числе с color key), клавиатура (коды клавиш не зависят от выбранной
  раскладки), мышь (положение, нажатие/отпускание кнопок), примитивы (рамка
  прямоугольника, мигающая рамка выделения), пауза, файловый доступ.
  Портируется заменой этого модуля.
- `src/readconfig.h/.c` — чтение конфигов: ini с секциями `{section}` (UTF-8);
  работает только через абстрактные файловые функции платформенного уровня.
- `src/utf8_win1251.h/.c` — перекодировка UTF-8 -> Windows-1251 (1 байт = символ).
- `src/font.h/.c` — отрисовка строк шрифтом `img/font.png` (тайлы 64x64,
  порядок задаётся chartable из конфига, ряды тайлов считаются снизу).
- `src/ui.h/.c` — абстрактный интерфейс: структура кнопки ui_button и массив
  всех кнопок игры, отрисовка/проверка нажатия кнопок, типовое окно,
  прогрессбар. Графика — 9-срезами из `img/windows.png`, координаты элементов
  задаются в `config/windows.cfg`.
- `src/main.c` — этап 2: загрузка конфигов и изображений с прогрессбаром,
  главное меню (title вверху экрана, кнопки «Новая игра» и «Выход» внизу,
  обработчик кнопки «Выход» завершает приложение) и выбор режима по
  параметрам командной строки (см. «Запуск»).
- `src/editor.h/.c` — редактор карт (запуск с "-ed"): режимы 1–4 —
  поверхности/стены, объекты, ассеты, невидимые блоки запрета передвижения.
- `src/game.h/.c` — игровой режим (запуск с "-map"): подсчет юнитов сторон,
  раздельный "туман войны" игрока и компьютера с раскрытием рейтингрейсингом
  лучами (луч останавливается блоком запрета передвижения), выбор объектов
  мышью с мигающей подсветкой, окно описания объекта по клавише "I".
- `src/objects.h/.c` — описания подбираемых объектов, фракций и персонажей
  из `config/objects.cfg` (загружаются при старте игры).
- `src/map.h/.c` — карта: слои тайлов, объекты, невидимые блоки, камера,
  реестр типов из `config/editor.cfg`, файл карты (RLE), отрисовка
  (опционально — с "туманом войны").
- `config/main.cfg` — основная конфигурация ({main}, {font}, {main_btns}).
- `config/windows.cfg` — координаты и размеры элементов интерфейса на
  `img/windows.png` ({skin}, {button}, {button_pressed}, {window},
  {progressbar}).
- `config/editor.cfg` — настройки редактора и игровой режим: размеры карты,
  видимость, скорость камеры, число видов подбираемых объектов ({objects}),
  типы персонажей {char1}..{char3} (tile_row, title_col, player).
- `config/objects.cfg` — описания подбираемых объектов ({objectN}), фракций
  ({char_typeN}) и персонажей ({characterN}).
- `img/` — графические тайлы и элементы интерфейса.

## Запуск

```
lrebel                # главное меню
lrebel -ed -filename map1.map   # редактор карт
lrebel -map map1.map  # игровой режим, минуя главное меню
```

В игровом режиме: WASD — камера (стартует на первом юните игрока), ЛКМ —
выбор объекта (юниты игрока — светло-синяя мигающая рамка, остальные —
зеленая), I — окно описания выбранного объекта (закрывается крестиком или
повторным I), ESC — выход в меню.
