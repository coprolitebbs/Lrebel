# Lrebel

Пошаговая стратегия в стиле Rebel Star (DOS). Написана на Си, архитектура
двухуровневая: верхний уровень (логика) работает через абстрактные функции
платформенного уровня, нижний уровень реализует их для конкретной ОС.

## Сборка (этапы 1–2)

Зависимости: SDL2 (dev-пакет). Заголовки и библиотека находятся через
pkg-config, при его отсутствии — через sdl2-config.

```
make          # соберёт build/lrebel
make run      # запуск (из корня репозитория)
make clean    # очистка
```

Структура:

- `src/portable_posix.h/.c` — нижний (платформенный) уровень: SDL2, Linux/macOS;
  окно, отрисовка кадра, загрузка изображений (PNG через встроенный stb_image.h),
  клавиатура, мышь (положение, нажатие/отпускание ЛКМ), пауза, файловый доступ.
  Портируется заменой этого модуля.
- `src/readconfig.h/.c` — чтение конфигов: ini с секциями `{section}` (UTF-8);
  работает только через абстрактные файловые функции платформенного уровня.
- `src/utf8_win1251.h/.c` — перекодировка UTF-8 -> Windows-1251 (1 байт = символ).
- `src/font.h/.c` — отрисовка строк шрифтом `img/font.png` (тайлы 64x64,
  порядок задаётся chartable из конфига, ряды тайлов считаются снизу).
- `src/ui.h/.c` — абстрактный интерфейс: структура кнопки ui_button и массив
  всех кнопок игры, отрисовка/проверка нажатия кнопок, типовое окно,
  прогрессбар. Графика — 9-срезами из `img/windows.png`, координаты элементов
  задаются в `config/windows.cfg`.
- `src/main.c` — этап 2: загрузка конфигов и изображений с прогрессбаром,
  главное меню (title вверху экрана, кнопки «Новая игра» и «Выход» внизу,
  обработчик кнопки «Выход» завершает приложение).
- `config/main.cfg` — основная конфигурация ({main}, {font}, {main_btns}).
- `config/windows.cfg` — координаты и размеры элементов интерфейса на
  `img/windows.png` ({skin}, {button}, {button_pressed}, {window},
  {progressbar}).
- `img/` — графические тайлы и элементы интерфейса.
